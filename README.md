# AGENTIC-ORBIT

**AGENTIC ORBIT** — AI-Powered Business Operating System & Global Corporate Formation Hub.

- **Non-Resident Formations**: UK LTD (Companies House), US LLC (Wyoming / Delaware).
- **Global Banking**: Verified Stripe, Wise, Tide, PayPal Business.
- **AI Operating System**: DIGI BIZ OS Desktop Voice AI, Autonomous WhatsApp Agents, Workflow Pipelines.
- **Frontend Architecture**: Modern React 19 + Vite 5 + Tailwind CSS + Three.js 3D Interactive Orbits.

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
